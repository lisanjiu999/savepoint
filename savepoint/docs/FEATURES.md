# SavePoint · 功能说明

> 给并行推进多个项目的人，一个本地优先的「上下文存档点」。

## 一句话

写着写着就忘了当初为什么这么做、卡在哪、下一步要干嘛——SavePoint 让你在做事时顺手留一行字，
几个月后翻出来，能立刻接上当时的思路。

## 适合谁

- 手上同时有几个副业项目 / 外包 / 学习项目
- 习惯「隔两周才回去碰一次」，回来要花半小时重新进入状态
- 不想把项目上下文交给 Notion、飞书这类云端协作工具
- 需要记录截图和零散结论，但不想为此维护一套笔记体系

## 核心功能

### 1. 项目卡片：每个项目的「当前状态」

一个项目一张卡：名称、状态（进行中 / 暂停 / 完成 / 归档）、标签、目录路径、一句话描述、下一步。

- 点「打开文件夹」直接跳转资源管理器
- 目录被移动或删除会标黄提醒，不会静默失败
- 状态下拉随手切换，不用进编辑框

### 2. 追加式记录：过程，而不是结论

这是和普通笔记最不一样的地方。每个项目下是一条**按时间排列的记录流**：

```
11-19 08:47  线程池改成 8 之后快很多，但目标站点开始返回 429
11-19 08:47  加了 0.5-1s 随机延时，还是限频。怀疑是 IP 段被盯上了
11-19 08:47  单线程版本能跑通 1000 条，用了 4 分钟
```

只追加、不改写，看到的是**完整的思考轨迹**。打错字可以编辑，时间戳保留原样。

### 3. 截图时间线：视觉记忆

比文字更快的回忆方式。三种录入方式：

- **拖拽**：把图片拖进窗口
- **粘贴**：`Ctrl+V` 直接收剪贴板截图
- **区域截图**：点「截图」→ 屏幕变暗 → 框选 → 松手自动入库

自动生成缩略图、按时间排列、同一张图自动去重。每张图配一句说明，点击看大图。

### 4. 回顾视图：解决「遗忘」本身

左侧两个专门的视角：

- **最近更新** —— 这几天在推进什么
- **长期未动** —— 进行中但超过 30 天没碰的项目

超过 30 天的项目，卡片上会挂一个橙色的「N 天未动」标记。**这些恰恰是最容易被忘掉、
也最需要被重新看见的**——普通笔记按更新时间排序，会把它们沉到最底下。

### 5. 全局搜索 `Ctrl+K`

一个输入框搜四类内容：项目、记录、笔记、截图说明。

回忆的时候你不知道答案存在哪个模块里。搜「代理池」，能同时命中项目描述和那条记录。

### 6. 活动流

把所有项目的记录合并成一条按日期分组的时间线。

回答的是「**我这周到底干了啥**」——不用逐个点开项目。

### 7. 笔记：独立的分区 / 文档树

和项目无关的零散信息：常用 Prompt、配置片段、账号备注、灵感。

- 左侧「分区 → 文档」折叠树，彩色标记
- 正文边写边存，停手 0.5 秒自动保存
- 右键菜单：重命名、删除、移动到其他分区
- 深色窗口，和主界面区分开

### 8. 快速记录 `Ctrl+Alt+N`：真正的低摩擦

在**任何程序里**按 `Ctrl+Alt+N`，弹出小窗：选项目、打字、回车。

记完就关，窗口都懒得找。托盘常驻，关主窗口默认最小化到托盘，不占任务栏。

## 数据安全

- **完全本地**：没有任何网络请求，没有遥测、没有账号
- **回收站**：删除的记录 / 截图 / 笔记保留 30 天，可单独恢复或彻底删除
- **滚动备份**：启动时自动打快照（数据库 + 截图），只留最近 N 份
- **一键恢复**：可以选择任意一份快照回滚，**回滚前自动把当前数据另存一份**
- **纯文件**：`savepoint-data` 目录拷走就是完整备份，不依赖任何数据库服务

## 技术特点

- Windows 10/11 原生应用，Python + PySide6 + SQLite
- 便携版解压即用，不写注册表，整个文件夹可以搬到别的机器
- 单实例运行，重复启动会把已有窗口唤到前台
- 数据库带版本号迁移，升级不丢数据

## 已知边界

刻意不做的：云同步、协作、任务管理、日历提醒、Markdown 渲染。

这个工具的定位是「记录发生过的事」，不是「管理要做的事」——一旦混进待办，
就会开始和专门的待办工具比较，最后两边都用不好。
